# 印向未来 · 实习与职业研究

在原版数字印刷网站上继续建设。首页现在支持自由填写专业，联动企业机会、职业路径与技能建议；企业库保留真实企业研究对象，联网查找公开新资料。另一份旧项目没有被改动。

## 已实现

- 12类专业能力映射，70个企业研究对象（含原版历史企业）；未知专业可联网研究，不硬填不对口企业。
- 企业目录从云端读取；刷新或重新回到页面检查新快照，网络失败明确显示备份。
- 实习公告、职业发展、学校培养/竞争准备三类实时联网检索，显示原始链接、检索时间与缓存状态。
- 24小时检索缓存；上线新检索须登录，每账号每天5次、全站每天50次，额度由数据库原子控制。
- 造纸、传统/数字印刷、色彩管理等职业环境和技术/管理路线；机长编制只按你提供的设备和班次作假设计算。
- 技能差距、按年级行动清单、证书目标、收藏与投递记录；登录授权后账号私有档案同步。
- 城市级机会分布雏形。精确地图和招聘平台投递进度自动追踪尚未实现。

**企业研究对象≠在招职位。** 现有种子没有伪造有效职位。检索结果是待核验线索，必须打开公告核实时间、地点和条件，才能通过维护工具录入已核验职位。不编造退休年份、晋升年限、人员学校分布，也不保证录用。

## 本地运行

已有依赖的项目直接运行：

```powershell
$env:NEXT_TELEMETRY_DISABLED='1'
npm run dev -- --hostname 127.0.0.1
```

打开 http://127.0.0.1:3000 。新环境先执行 npm install。Windows遇到Next遥测文件跨盘错误时，上面的环境变量可关闭遥测。

未配置云端时仍可浏览基础目录。要实际联网研究，在服务器环境设置 FIRECRAWL_API_KEY；仅本机开发测试可另设 ALLOW_LOCAL_RESEARCH=true（生产环境不生效）。公开服务必须按下方说明配置账号和持久额度，不能用本机测试开关代替。

## 数据刷新与上线

查看 [数据维护与上线说明](docs/DATA-OPERATIONS.md)。执行新版 supabase/schema.sql，再发布目录快照。云端快照更新后，页面刷新即可加载，不需要重新构建网站。

```powershell
npm test
npm run build
node scripts/publish-catalog.cjs
node scripts/research-smoke.cjs
```

上述发布工具默认只在本地校验，不写云端。联网检查加 --live 才会使用检索积分。

**本版需要Next服务器运行，不再是GitHub Pages静态导出。** 可使用支持Next运行时的平台或Node服务器：npm run build 后 npm start。原版 deploy/publish 脚本面向旧静态版本，不要用于本版。本任务没有发布公网，没有替你执行数据库迁移或创建用户账号。

## 简历与隐私

原版浏览器文本/PDF简历解析保留为可选功能，不参与联网检索，也没有上传图片到AI的功能。联网请求只发送专业、企业与研究主题；私有档案同步须登录和明确授权。共享设备仍应清理浏览器数据或使用独立浏览器账号。上线还需要隐私说明、数据库权限实测及服务监控，不保证“零漏洞”。
