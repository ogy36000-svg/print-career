# 职景 · 实习与职业发展

在原版网站上继续建设。首次填写专业和年级后，进入个人工作台：查看公开招聘公告、了解相关企业，安排学习和投递准备。优先整理数字印刷与印度尼西亚语方向，其他专业可自由填写并查找公开资料。另一份旧项目没有被改动。

## 已实现

- 两步首次指引、账户隔离的专业/年级选择；固定品牌，内容随专业和阶段变化。
- 14类专业映射，70个企业研究对象（含历史企业）；数字媒体、印尼语独立匹配，未覆盖专业不填入无关印刷企业。
- 公开来源刷新接入首页：整理公告、往期届别、职业参考和新发现的资料链接分组展示，保留原始链接与每条读取日期。
- 页面可见时每15分钟检查已接入来源；“更新资料”重读来源，“搜索更多公告”主动调用检索服务。没有模型调用或生成式摘要。
- 公开读取使用固定注册表、超时和大小上限；检索服务缓存24小时，生产环境新检索仍需要登录与服务器额度控制。
- 整块企业卡片可阅读跳转，收藏和官网操作独立；企业介绍与公告条件分开，收藏、投递状态、成长勾选保留。
- 按专业和年级展示职业工作内容、行业/海外视角、学习目标和行动清单；没有简历信息时不推断个人技能缺口。
- 城市/地区级地图雏形，带来源标注、缩放范围及地点列表。精确工作地点和招聘平台投递进度自动追踪尚未实现。

企业目录不是在招职位库；当前没有人为填入未经确认的有效岗位。往期公告不会因为重新读取就变为当前实习。检索结果是公开资料线索，可能有高校工作人员招聘等并不适合本科实习的内容，需打开原文确认对象、时间和条件。不编造退休年份、晋升年限或往届录用学校分布。

## Vercel上线配置（2026-11-05）

本项目是Next.js动态服务。部署时应选择Next.js框架，以本仓库根目录构建，执行npm ci与npm run build；不把源码子目录当静态发布目录。vercel.json已经声明这些配置，.vercelignore排除本机环境变量、缓存、日志和工具目录。需要的生产密钥通过平台环境变量单独配置。

原线上部署曾出现控制台Ready但公开首页404；检查发现它以无框架静态项目上传了src中的Next源码，没有生成有效的页面／服务输出。本次修复部署配置并重新发布，实际验证结果见本次上线记录。

## 本地运行步骤

Windows双击根目录“**双击启动_职景实习网站.cmd**”。入口会安装缺失依赖、启动或复用完整Next开发服务，等首页就绪后再打开浏览器。日志在.runtime；用“**双击停止_职景实习网站.cmd**”结束本项目后台进程。默认只监听127.0.0.1:3000，关闭浏览器不会自动停止服务。

已有依赖的项目直接运行：

```powershell
$env:NEXT_TELEMETRY_DISABLED='1'
npm run dev -- --hostname 127.0.0.1
```

打开 http://127.0.0.1:3000 。新环境先执行 npm install。Windows遇到Next遥测文件跨盘错误时，上面的环境变量可关闭遥测。

未配置云端时仍可浏览整理的企业目录。公开学校来源刷新不需要模型或检索服务密钥；主动搜索更多网页需要服务器 FIRECRAWL_API_KEY。仅本机开发测试可另设 ALLOW_LOCAL_RESEARCH=true（生产环境不生效）。公开服务须配置账号和持久额度，不能用本机开关代替。

## 数据刷新与上线

查看 [数据维护与上线说明](docs/DATA-OPERATIONS.md)。公开读取目前覆盖六个整理原文地址和四个学校列表，每个列表最多读取三个同站公告正文，不是全网招聘数据库。进程缓存重启后会重读；更多专业和地区需继续扩充可信来源。云端目录快照可以独立更新，专业模板和来源注册表的修改仍需部署代码。

如需云端档案，先按维护说明备份并迁移数据库，再发布目录快照；本次没有执行云端迁移或发布。

```powershell
npm test
npm run build
node scripts/publish-catalog.cjs
node scripts/research-smoke.cjs
```

上述发布工具默认只在本地校验，不写云端。联网检查加 --live 才会使用检索积分。

可选账号切换浏览器回归：在 artifacts/browser-runtime 单独安装 Playwright 后运行 node tests/owner-lifecycle.cjs。此脚本使用本机 Windows Chrome、真实组件与受控模拟账号，不需要真实账号或收费检索；不包含在 npm test 的56项单元检查中，也不替代线上数据库权限测试。

**本版需要Next服务器运行，不再是GitHub Pages静态导出。** 可使用支持Next运行时的平台或Node服务器：npm run build 后 npm start。原版 deploy/publish 脚本面向旧静态版本，不要用于本版。本任务没有发布公网，没有替你执行数据库迁移或创建用户账号。

## 简历与隐私

文本/PDF简历解析保留为档案页可选功能，原文件在浏览器处理，没有图片OCR或模型上传。确认填入的文字、技能等属于个人档案，仅在登录并明确开启同步后保存到账号。公开检索只发送专业、企业与主题，不发送简历或联系方式。共享设备仍应清理浏览器数据或使用独立浏览器账号。上线还需隐私说明、数据库权限实测及服务监控，本地检查不是公网安全保证。
